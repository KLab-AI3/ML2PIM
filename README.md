# COMPASS: An Extensible Framework for Design Space Exploration of PIM Architectures

COMPASS is an extensible framework for design space exploration (DSE) of DRAM-based Processing-in-Memory (PIM) architectures. It integrates high-level programming support with an MLIR/LLVM-based compilation flow, configurable PIM hardware abstractions, and performance simulation to enable systematic evaluation of different workloads, software mappings, and PIM architecture configurations.
